## 文档使用约定

1. 本文是本 Demo 的唯一实施基线。发生冲突时，优先级固定为：本文明确规则 ＞ 2026-07-20 运行态 Demo 与证据截图 ＞ AGENTS.md 中“Durable Prototype Decisions” ＞ 同日 QA 文档 ＞ 旧版 PRD/归档文档。
2. “必须”表示验收阻断项；“不得”表示禁止实现；“应”表示不改变业务结果时必须遵循的默认方案。
3. Demo 当前使用前端常量和 React 本地状态模拟数据，不存在真实 API、权限服务、埋点服务。本文第 7～10 章给出正式实现的强制契约；正式实现不得继续使用硬编码统计值或无结果的装饰性按钮。
4. 页面 1:1 还原的含义包括：布局、密度、字体层级、色彩、组件 anatomy、默认文案、数据状态、键鼠行为、焦点管理、加载/失败/恢复路径和跨页面参数，不仅是静态截图相似。
5. 正式实现中的服务端字段值以接口为准；若接口未返回可选能力，前端必须显示明确禁用原因，不得猜测能力或静默执行。

名词定义：

- “当前条件”：用户已确认并已驱动结果区的查询条件。
- “草稿条件”：右侧面板中已编辑、尚未点击“确定”的条件。
- “脏状态”：当前草稿与最近一次成功保存的服务端基线存在结构化差异。
- “告警点”：某个指标在某个毫秒时间戳上的一次采样及其告警判定。
- “附件”：与采样点关联的图片、视频或音频波形证据。
- “绑定”：采集站数据 ID、监测功能与算法配置之间的持久关系。
- “命令”：下发参数、重启、自检、抓拍、PTZ 等具有执行状态的服务端任务。

# 三、页面内所有控件完整交互细则

## 3.1 统一权限、点击与反馈规则

1. view 权限决定模块导航及整页可见性；action 权限默认隐藏纯操作按钮。为了让用户理解状态而必须保留的控件采用禁用态并显示原因，具体见第 8 章。
2. 每个可见按钮必须满足下列之一：产生业务结果、改变可见状态、发起下载/跳转、打开有内容的浮层，或以禁用态明确说明不可用原因。不得保留点击无反应的装饰控件。
3. 普通提交按钮在客户端校验通过后立即进入 Loading；服务端返回前禁止二次提交。业务写接口携带 Idempotency-Key。
4. 成功 Toast 默认 2.4s，信息 2.4s，警告 4.2s，错误不自动关闭或最少 6s；错误 Toast 必须提供关闭按钮。阻断式错误使用局部错误页或弹窗，不用 Toast 替代。
5. Popover、下拉、右键菜单点击外部或按 Esc 关闭；再次点击触发器也关闭；关闭后焦点回到触发器。模态关闭规则见第 6 章。
6. 所有下载在开始时 Toast“正在生成文件…”，成功后“文件已开始下载”，失败显示可重试错误。文件名格式见 7.8。

# 四、表单全链路交互与校验逻辑

## 4.1 通用输入与校验

1. 文本输入使用受控值；maxlength 是输入上限而非提交时截断。达到上限后拒绝更多字符，并在右下显示 n/N；中文按 Unicode 字符计数，不按字节。
2. 输入法 composition 期间不执行过滤、搜索或校验；compositionend 后统一处理。
3. 数字输入允许编辑中间态空字符串和单个负号；失焦时规范化。禁止指数记法、Infinity、NaN。小数位超限时阻止输入，不静默四舍五入；粘贴非法字符时过滤并提示一次。
4. 金额字段本 Demo 当前不存在；未来如新增，内部以最小货币单位整数存储，展示千分位和两位小数。
5. 手机号字段本 Demo 当前不存在；未来如新增，仅接受中国大陆 11 位 1 开头手机号并按 3-4-4 展示。
6. 日期选择以自然日 00:00:00.000～23:59:59.999 传参；手输格式 YYYY-MM-DD；无效日期、未来日期或范围超限分别报错。
7. 有清除按钮的输入在非空且可编辑时显示；点击清空后焦点留在输入。Readonly 不显示清除，Disabled 不响应复制之外的动作。
8. 校验时机：输入中只做长度/字符级限制；失焦做字段校验；提交做全表单校验；服务端 422 合并显示。错误优先级为：必填 ＞ 格式 ＞ 范围 ＞ 跨字段 ＞ 服务端业务规则。
9. 错误文本位于字段下方 4px；控件红边；弹窗提交后自动滚动并聚焦首个错误。修正后失焦即清除对应错误。
10. Enter：单行表单触发主提交；多行 textarea 中 Enter 换行、Ctrl/Cmd+Enter 提交。提交中 Enter 无效。Esc 只执行关闭/恢复，不清空输入。

| 代理端口 | 数字 | 启用时必填；1～65535 | 正整数 |
| 监测位置描述 | 文本 | 可空；0～50 | 失焦 trim |

动态算法参数由 GET /api/v1/algorithms/{algorithmId}/schema 返回；前端只按 schema 的 type、required、min、max、step、enum、unit 渲染，未知类型阻止保存并报告“算法参数定义不受支持”，不得自由猜测。

网络/代理弹窗的“确定”只合入站点草稿；“保存”才写服务端。取消时有局部改动弹出“放弃本次设置修改？”。

### 标注区域校验

- regionId：UUID，创建后永久不变。
- x、y、width、height：0～1，最多 6 位小数；width/height≥0.05；x+width≤1；y+height≤1。
- name：trim 后 1～30 字，同一 functionId 下不区分大小写唯一。
- color：#RRGGBB。
- order：从 0 连续递增，不得重复。
- annotated=true 且 noAnnotation=false 的功能至少 1 个有效区域。
- 功能显隐关闭时不删除区域；绘制条件为 function.visible && region.visible && !noAnnotation。

## 4.5 音视频分析与托辊查询表单

| 字段 | 规则 |
|---|---|
| 开始日期 | 必填；不得晚于结束日期；与结束组成最多 30 个自然日 |
| 结束日期 | 必填；不得晚于今天；默认今天 |
| 快捷范围 | 1/7/15/30 天，均包含结束日；点击后只改草稿 |
| 测点 | 单选；必须来自当前权限范围和 treeVersion；切换即自动查询 |
| 指标 | 分组多选；至少 1 项；只能选择测点 compatibleMetrics |
| 只看异常托辊 | boolean；托辊页默认 true |
| 严重度/附件状态 | 多选；空集合代表全部 |

确认优先校验：必填 → 日期格式 → 结束≥开始 → 结束≤今天 → ≤30 天 → 至少一个指标 → 指标兼容性。失败不覆盖旧图表。成功后把草稿复制为当前条件，更新 URL 中可分享参数但不写入每个临时图表状态。

## 4.6 智能诊断表单

### 关闭病例

- 原因：必填，trim 后 1～120 字；支持换行；显示 n/120。
- 批量关闭只填写一次原因，服务端为每个事件写独立处理记录。
- 提交前展示“将关闭 N 条报警”；N=1 时显示具体标题。

### 生成缺陷字段与映射

| 字段 | 编辑性/校验 | 单条映射 | 批量映射 |
|---|---|---|---|
| 缺陷名称 | 可编辑，必填 1～80 | 病例标题 | 分组标题；非分组为第一条标题并加“等N项” |
| 缺陷等级 | 可编辑，必填 | 由告警级别映射 | 取选中事件最高级别 |
| 诊断时间 | 只读，必填 | 当前服务端时间 | 当前服务端时间 |
| 设备部件 | 可编辑/选择，必填 | event.devicePart | 第一条排序事件 |
| 故障部件 | 可编辑/选择，必填 | event.faultPart | 第一条排序事件 |
| 故障类型 | 可编辑/选择，必填 | event.faultType | 第一条排序事件 |
| 设备路径 | 只读 | event.devicePath | 共同设备路径；不一致则列出唯一值 |
| 位置描述 | 可编辑，max100 | event.locationDescription | 去重后按“；”连接 |
| 测点 | 只读多值 | event.measurementPoint | 去重后保留全部 |
| 故障现象 | textarea，必填 1～1000 | 当前证据现象 | 按事件时间顺序合并，重复句去重 |
| 诊断结论 | textarea，必填 1～1000 | event.conclusion | 第一条排序事件的结论 |
| 维修建议 | textarea，必填 1～1000 | 运行建议＋维护建议 | 第一条排序事件的建议 |
| 备注 | textarea，可空 max500 | 空 | 空 |
| 关联告警 | 只读表格 | 一事件一行 | 每个选中事件一行，不聚合丢失 |

缺陷弹窗包含“基本信息 / 关联告警 / 诊断报告”Tab。诊断报告实时由草稿生成，空章节完全不渲染标题。编辑原有缺陷时 GET 最新版本回填；未修改字段保持服务端原值，null 显示为空而不是字符串“null”。

## 4.7 重置、草稿和编辑回填

- 普通筛选“重置”：恢复页面默认筛选并立即查询；分析右栏“重置”只恢复草稿，必须再点“确定”。
- 采集站显式“撤销全部”：恢复当前站点保存基线，二次确认。
- 站点草稿本地缓存键：os:station-draft:{userId}:{stationId}:{baseVersion}，保存 24h；只缓存配置值，不缓存令牌、媒体 URL 或个人敏感信息。
- 恢复草稿前比较 baseVersion；一致时提示“发现未保存草稿，恢复/忽略”；不一致时进入只读对比，不允许直接覆盖。
- 其他弹窗草稿只保留到弹窗关闭；有 dirty 时按第 6 章确认，不写 localStorage。
- 服务端回填完成前表单不可编辑；回填后的 select 必须用稳定 ID 匹配，不用显示文案匹配。

# 一、页面整体业务逻辑说明

## 1.1 核心定位与使用场景

智能运维 OS 是面向值班员、运维工程师、算法工程师和管理人员的桌面诊断工作台。全局框架负责模块导航、账户、通知和工作区伸缩；各模块承接以下闭环：

| 模块 | 核心任务 | 完成标准 |
|---|---|---|
| 智慧视频监控 | 发现告警 → 核实对应画面/历史证据 → 填写原因 → 关闭或转缺陷 | 告警状态、处置记录、统计和队列同步更新 |
| 智能诊断 | 筛选待处理病例 → 核查结论、依据和现场图像 → 生成缺陷或填写原因关闭 | 单条或批量病例进入已成缺陷/已关闭，生成处理记录 |
| 采集站管理 | 定位站点 → 检查运行上下文 → 编辑配置/绑定/标注 → 校验 → 保存或下发 | 草稿持久化、版本更新、脏状态清除、命令可追踪 |
| 音视频分析 | 选择音/视频测点 → 选指标与时间 → 查询 → 联动查看采样和附件 → 标记/导出 | 当前条件、图表、数据行、附件保持同一上下文 |
| 托辊组分析 | 接收报警托辊上下文 → 仅分析异常托辊及近 15 天指标 → 查看附件 → 返回诊断 | 查询结果与深链参数一致，可回到来源病例 |

主页只展示欢迎信息，不承载业务卡片、统计或快捷入口；入口统一放在左侧主导航，避免重复信息架构。

## 1.2 全局业务流与页面关联

1. 用户完成 SSO 登录后进入原始目标地址；无目标地址时进入主页。
2. 前端先加载会话与权限，再渲染有权访问的导航；业务页数据请求不得早于权限请求完成。
3. 智慧视频监控中点击告警“定位画面”只切换视频墙当前画面，不改变右侧告警筛选或自动关闭告警详情。
4. 智慧视频监控和智能诊断的“生成缺陷”成功后，缺陷编号必须可点击跳转 /defects/{defectId}；无 defect.view 权限时显示纯文本编号和 Tooltip“无缺陷详情查看权限”。
5. 智能诊断音/视频病例的“进入分析”跳转：
   /audio-video-analysis?point={pointId}&metric={metricCode}&alarmTime={ISO8601}&days=15。
6. 智能诊断托辊病例的“进入托辊组分析”跳转：
   /roller-group-analysis?device={deviceId}&location={locationId}&metric={metricCode}&alarmTime={ISO8601}&days=15&queryMode=abnormal-roller。
7. 音视频分析或托辊组分析的“返回诊断”优先调用 history.back()；若无站内来源历史，则跳转 /intelligent-diagnosis?caseId={sourceCaseId}，恢复原病例和滚动位置。
8. 采集站管理存在脏状态时，站点切换、主导航跳转、浏览器后退、刷新和关闭页签均触发保存/放弃/取消保护；选择“取消”必须留在原上下文。
9. 会话失效时保留可恢复的纯前端草稿，跳转登录并携带 returnUrl；重新登录后恢复目标页和未过期草稿，但不得自动提交。

## 1.3 各模块完整主链路

### 1.3.1 智慧视频监控

1. 初始化设备树、已勾选摄像头、视频布局、告警摘要和告警队列。
2. 值班员用“全部/在线/离线/已选”及关键词过滤设备；勾选决定视频墙轮巡集合，单击设备仅临时查看。
3. 默认 2×2 视频墙，用户可切换 1/4/9 分屏、分页、开始轮巡、进入专注监控或打开单画面。
4. 右侧“告警看护”默认可见。选中告警同步告警详情和对应摄像头，但点选其他视频画面不得切走告警队列。
5. 用户查看实时画面和报警证据；原图完整显示，禁止把关键目标裁出画面。
6. 对待处理告警选择“关闭告警”或“生成缺陷”，填写必填原因后提交。
7. 成功后更新告警状态、操作人、处理时间、原因、缺陷编号、摘要统计及当前筛选队列；若当前筛选不再包含该项，播放淡出 160ms 后移除并把焦点移至相邻项。
8. PTZ、手动录像、回放、重连、抓拍均形成可见执行状态；轮巡在弹窗、回放、PTZ 按压、页面后台和单画面期间自动暂挂，条件解除后才恢复。

### 1.3.2 智能诊断

1. 默认进入“诊断分析 / 待处理”，加载状态数量和第一页病例，默认选择首条。
2. 通过状态、模块、关键词和排序筛选病例；选择病例同步结论、建议、趋势/现场图像和证据点。
3. 待处理托辊告警仅在同一“故障部件 + 故障类型”至少有两个故障位置时分组；严重度和时间取最新事件。
4. 打开托辊分组后，左栏替换为分组明细列表，3 条/页，可跨当前分组多选并批量生成缺陷/关闭。
5. 单条或批量生成缺陷时按第 4.5 节映射字段；每个事件保留一条关联告警，报告不展示空章节。
6. 关闭病例必须填写原因。成功后每个事件追加一条处理记录，移动到相应队列并更新数量。
7. 音视频证据跳转音视频分析；托辊证据只能跳转独立托辊组分析，不得套用通用音视频指标。

### 1.3.3 采集站管理

1. 默认站点为 08300008；默认一级 Tab“板卡集合”、二级 Tab“算法标注”。
2. 左侧分别按站点编码、站点名称做模糊过滤，并按全部/在线/离线过滤；每行同时显示编码、名称和状态。
3. 选择站点后加载详情、配置、已绑定设备、算法功能和保存基线；切换前处理原站脏状态。
4. 用户可编辑板卡参数、网络、代理、算法设置、绑定设备和标注区域。脏状态由各区草稿与已保存基线逐字段深比较得出，不允许仅用“发生过 change”判断。
5. 算法绑定只允许新增真正未绑定的功能；已绑定功能在级联选择器中保持选中且锁定。再次绑定同一数据组时按创建顺序合并功能。
6. 标注区域以稳定 ID 和 0～1 归一化矩形保存；名称、颜色、显隐、顺序、位置、尺寸和“无需标注区域”全部随站点草稿持久化。
7. 保存前执行全量同步校验；成功后更新配置版本和保存时间，并替换基线。参数下发、重启、自检等命令与草稿保存分离。

### 1.3.4 音视频分析

1. 默认选择首个可用音/视频测点，时间为含当天在内最近 15 天，兼容指标全部选中并自动查询。
2. 切换测点会重置为最近 15 天、全选兼容指标、选中最新有效采样并自动查询；不同点位只能显示其兼容指标和附件类型。
3. 编辑日期、指标等只改变草稿；点击“确定”且校验通过后才替换当前条件并查询。
4. 图表数量按已选指标自适应：1 个指标 600px，2 个各 300px，3 个及以上各 178px；所有图表共享时间游标。
5. 点击任意采样点同步毫秒时间戳、当前指标值、逐指标告警依据、数据行和右侧附件。正常指标不得因同时间其他指标告警而染红。
6. 工具栏和右键菜单支持游标、标注、报警线、伪信号、波形分析、证据、重置、设置、导出和全屏，均需有真实状态或明确禁用原因。

### 1.3.5 托辊组分析

1. 从深链读取设备、位置、报警指标、报警时刻、天数和 queryMode；默认近 15 天，最大 30 天。
2. queryMode=abnormal-roller 时默认只勾选异常托辊，报警托辊排在首位并自动选中。
3. 左侧托辊列表、中心趋势/附件和右侧查询条件必须使用同一托辊 ID；切换托辊后附件同步。
4. “确定”验证日期和指标后执行查询；“返回诊断”恢复来源病例。

## 1.4 页面初始化时序与默认请求

所有请求必须携带请求头：

- Authorization: Bearer {accessToken}
- X-Request-Id: 前端生成 UUID v4
- X-Timezone: Asia/Shanghai
- X-Locale: zh-CN
- X-Client-Version: 构建版本号

全局初始化顺序：

1. GET /api/v1/session；超时 10s。
2. 并行 GET /api/v1/session/permissions、GET /api/v1/users/me/preferences、GET /api/v1/notifications?limit=20&includeRead=true。
3. 应用导航宽度、折叠状态、模块级本地偏好；越界或解析失败时使用默认值并清除损坏缓存。
4. 根据路由与 view 权限发起业务初始化请求。
5. 页面主骨架可立即显示；业务请求未完成前不得显示前次路由数据。

| 页面 | 初始化请求 | 默认入参 | 默认展示 |
|---|---|---|---|
| HOME | 无业务请求 | — | 欢迎语；通知和账户来自全局请求 |
| VIDEO | devices/tree、video-preferences、alarms/summary、alarms | status=all；alarmStatus=pending；sort=level,SLA,wait；page=1,pageSize=20 | 恢复本地最多 9 个已选摄像头；无有效缓存则取前 4 个在线摄像头；2×2；告警区展开 |
| DIAG | diagnosis/counts、diagnosis/cases | module=diagnosis；status=pending；sort=alarmTime,desc；page=1,pageSize=20 | 选中首条；首次用户显示引导 |
| STATION | stations、station/{default}/configuration | codeLike/nameLike 为空；status=all；stationId 优先取 URL，其次 08300008 | 站点树展开；板卡集合/算法标注；配置基线 |
| AVA | analysis/points/tree、analysis/audio-video/query | end=today 23:59:59.999；start=end-14 天 00:00:00；首测点；metrics=全部兼容指标 | 自动查询；选中最新有数据采样；树和附件展开；右栏 292px |
| ROLLER | analysis/roller/query | 解析深链；days 默认 15、限制 1～30；queryMode=abnormal-roller | 报警托辊优先；自动查询；无合法深链显示参数错误恢复页 |

页面恢复规则：

- 浏览器刷新：恢复 URL、服务端偏好和允许持久化的本地偏好；重新请求业务数据。
- 站内返回：恢复筛选、页码、列表滚动、选中行和图表游标；缓存有效期 8h。
- 硬链接：仅以 URL 参数初始化，不依赖前一页内存。
- URL 中未知 point/metric/station/case：忽略单个无效可选参数并 Toast“部分定位条件已失效，已按默认条件展示”；必需参数全部无效时显示“目标数据不存在”。

## 1.5 加载、空数据、异常与边界兜底

### 1.5.1 通用展示结构

- 首次加载：保留页面外壳和固定表头；内容区显示与真实布局等高的骨架屏，300ms 内完成的请求不显示骨架，避免闪烁。
- 刷新加载：保留旧数据并加 8% 白色局部遮罩；相关按钮显示旋转器和“查询中/保存中/执行中”，不得让整个 OS 白屏。
- 空状态：居中 96×96px 中性线性插图、16px 标题、13px 说明和一个恢复按钮；表头、筛选区和分页位置保持不变。
- 错误状态：错误图标、明确标题、可行动说明、requestId（可复制）和“重试”；不得只显示“系统异常”。
- 局部失败：只替换失败区域；其他成功区域继续可用，并在顶部显示可关闭警告条。
- 图片失败：灰蓝占位、图片图标、“图片加载失败”、重试按钮；三次失败后显示“在新窗口打开原始地址”。

### 1.5.2 全量异常矩阵

| 场景 | 页面表现 | 文案 | 恢复行为 |
|---|---|---|---|
| 列表首次加载 | 表体骨架，5～8 行；筛选可见但提交禁用 | “正在加载…”供读屏器读取 | 成功替换；失败进入对应错误态 |
| 搜索无结果 | 空表体，不清空条件 | “未找到符合当前条件的数据” | 主按钮“清空筛选”恢复默认条件并自动查询 |
| 数据源本身为空 | 空表体 | “暂无数据”＋业务说明 | 有新增权限才显示“新增”；本系统无新增入口的模块显示“刷新” |
| 接口 408/请求超时 | 局部错误 | “请求超时，请检查网络后重试” | 重试沿用原参数；自动重试最多 1 次，仅限幂等 GET |
| 浏览器离线 | 顶部持续警告条，写操作禁用 | “网络已断开，当前仅可查看已加载数据” | online 事件后自动重试最近失败的 GET，不自动重放写操作 |
| 400 | 表单或页面错误 | 使用服务端 fieldErrors；无字段信息时“请求参数不正确” | 聚焦首个错误字段 |
| 401 | 阻断式会话提示 | “登录状态已失效，请重新登录” | 保存允许的草稿，跳转登录，携带 returnUrl；不得循环重试 |
| 403 页面权限 | 全页 403 | “无权访问该模块，请联系管理员” | “返回首页”；导航中隐藏该模块 |
| 403 操作权限 | 控件隐藏或禁用，规则见第 8 章 | “无此操作权限” | 保持当前页，不重试 |
| 404 | 目标区空状态或全页 404 | “目标数据不存在或已被删除” | “返回列表”；清除失效选中项 |
| 409 | 冲突弹窗 | “数据已被其他用户更新” | 提供“重新加载”“对比更改”；禁止覆盖保存 |
| 410 | 媒体/下载失效 | “资源已过期，请重新生成” | 重新请求临时地址 |
| 422 | 字段校验 | 精确展示服务端字段文案 | 合并客户端校验，服务端优先 |
| 429 | 顶部警告 | “操作过于频繁，请 {retryAfter}s 后重试” | 倒计时内禁用对应操作 |
| 500 | 局部或全页错误 | “服务暂时异常，请稍后重试” | 展示 requestId，允许复制与重试 |
| 502/503/504 | 维护/网关错误 | “服务暂不可用，请稍后重试” | GET 采用 1s、2s 指数退避重试 2 次；写请求不自动重试 |
| 数据解析失败 | 局部错误并记录前端日志 | “返回数据格式异常” | 不展示残缺数据；提供重试 |
| 空媒体附件 | 媒体区保持尺寸 | “该采样点无现场附件” | 提供上一条/下一条有附件点，若无则禁用并提示 |
| 命令长时间执行 | 进度条保持 | “任务仍在执行，可稍后在任务中心查看” | 30s 后转后台任务并返回 operationId |
| 删除/失效的当前项 | 从列表移除后选相邻项 | “当前数据已不存在，已为你切换” | 优先下一条，否则上一条；列表空则空状态 |

### 1.5.3 并发与过期响应

- 每个查询域只能有一个有效请求。条件变化时 AbortController 取消前请求；不能取消的响应以 requestSequence 丢弃过期结果。
- 写操作以业务对象 ID + 操作类型加锁；同一对象同一操作在结果返回前不得再次提交。
- 列表刷新不得覆盖打开弹窗中的未提交草稿；若对象版本变化，提交时进入 409 冲突处理。
- 时间统一使用服务端 UTC ISO 8601，展示时转换 Asia/Shanghai；毫秒必须保留三位。

## 2.2 字体与文本

- 字体栈：Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif。正式包必须内置 Inter 或删除 Inter 声明，避免不同终端字宽漂移。
- 字重只允许 400、500、600、700；不得依赖 420、520、650 等浏览器合成字重。
- 品牌名称：23px/32px，600。
- 页面标题：18～20px/28px，600。
- 区块标题：14px/22px，600。
- 正文和常规控件：13px/20px，400；强调 500。
- 辅助标签：11～12px/16px，400；不得承载唯一错误原因。
- 按钮：13px/20px，500。
- 时间、数值和统计统一 font-variant-numeric: tabular-nums。
- 单行内容默认一行省略；Hover 500ms 或键盘聚焦立即显示 Tooltip，Tooltip 位于目标上方 8px，空间不足时自动翻转。
- 多行说明默认最多 3 行；超过时显示“展开”，展开后按钮变“收起”并保留原滚动锚点。表格单元格不得多行展开，完整内容只在 Tooltip/详情中展示。
- Tooltip 最大宽 360px、12px/18px、深色 #25364C 背景、白字、圆角 4px、内边距 6px 8px；不能仅使用原生 title。
- 用户输入换行按原样保留，展示时 white-space: pre-wrap；所有展示值进行 HTML 转义。

## 2.3 间距、圆角、边框与阴影

间距 Token 为 2、4、6、8、12、16、20、24px；模块内部只从该序列取值。页面工作区默认左右 22px、底部 20px、顶部为 54px 顶栏 + 11px。

- 输入、密集按钮、表格内控件：4px 圆角。
- 卡片、菜单、业务浮层：6px。
- 普通业务弹窗：8px。
- 账户弹窗、品牌、助手等框架级元素：10～14px。
- 常态边框 1px；选中 Tab 下划线 2px；列表选中左线 3px；标注矩形 2px。
- 面板阴影：0 2px 8px rgba(38,64,98,.06)。
- 下拉阴影：0 10px 28px rgba(32,48,68,.18)。
- 模态阴影：0 24px 70px rgba(22,38,58,.28)。
- 焦点环：0 0 0 2px rgba(8,105,238,.12)，并保留 2px 主色外轮廓。

## 2.4 通用控件全状态

| 状态 | 视觉 | 行为 |
|---|---|---|
| Default | 白底、1px #D9E2ED、主文字 | 可点击/输入 |
| Hover | #F2F7FD 浅底、#7EB4F7 边框、图标主色 | 仅指针设备触发 |
| Active | #DDEBFF，允许下移 1px，80～120ms | mouseup 后恢复 |
| Focus-visible | 2px 主色轮廓，外扩 2px | 键盘焦点必须可见 |
| Selected | #EAF2FF、主色文字；列表 3px 左线或 Tab 2px 下线 | aria-selected=true |
| Disabled | 禁用 Token，不响应 Hover/点击，不进入 Tab 序列 | Tooltip/相邻说明给出原因 |
| Readonly | #F6F8FB，文字正常可读，允许聚焦、选择和复制 | 不显示清除按钮 |
| Loading | 保持原宽，前置 14px 旋转器，使用“保存中”等进行时文案 | aria-busy=true，锁定重复提交 |
| Error | #E94B55 边框，字段下方 4px 显示错误文本 | aria-invalid=true，关联 aria-describedby |
| Success | 仅短时显示绿色对勾或局部说明 | 2s 后回到常态 |

主按钮高度 32px，横向内边距 14px；普通按钮 30～32px；密集图标按钮不得小于 28×28px，常规图标按钮 36×36px。图标仅允许 14/16/18/22px 四档，线宽 1.75～2。纯图标按钮必须有 aria-label。

按钮防抖规则：

- 查询/搜索：300ms 防抖，Enter 立即执行并取消待执行计时。
- 普通按钮：一次 pointerup 触发，不做额外节流。
- 写操作：从点击到响应完成使用对象级互斥锁；再次点击 Toast“操作正在处理中，请勿重复提交”。
- PTZ 按压：pointerdown 开始、pointerup/pointercancel/pointerleave/window blur/visibilitychange 停止，停止命令最高优先级。

## 2.5 全局 OS 框架

- 顶栏固定 54px，白底、底边框 #E6E9EF，左右内边距 29px/20px，z-index 110。
- 品牌图标 34×34px、圆角 10px；应用切换按钮 35×35px。
- 顶栏图标按钮 38×38px、圆角 8px。
- 左导航默认宽 clamp(286px,16.75vw,344px)，允许拖拽 220～480px；本地持久化。导航项最小高 58px、圆角 12px、图标 22px、文字 19px。
- 桌面收起后导航完全移出屏幕，工作区扩展至左侧边缘；左下 12px 保留 39×39px 恢复按钮，不得保留图标窄栏。
- 全局不显示“主页/当前模块”已打开页面标签行。
- 内容卡高度填满剩余工作区、白底、overflow:hidden；滚动由模块内指定容器承担。
- 助手按钮 49px 圆形，右 17px、下 14px；面板宽 270px。
- 移动端 ≤900px 时左栏变 320px 或 86vw 抽屉，工作区取消左边距；复杂业务工作台不做手机端重排。

## 2.7 表格、图表与图片

- 表头使用独立固定头或 position:sticky，表体滚动时表头不得移动。
- 文字默认左对齐；数字、金额、时长右对齐；状态、复选框、短操作居中。
- 表格 Hover #F7FAFD，选中 #EAF2FF；键盘焦点行显示 2px 内焦点环。
- 图表使用稳定 viewBox；不得使用会随容器非等比扭曲曲线的 preserveAspectRatio="none"。
- 网格使用弱虚线；主曲线 #3679FA；告警 #F04444；正常 #2EAE65。
- 采样点：无附件为空心蓝点，有附件为实心蓝点，告警为红点，选中点加外环；必须同时在 Tooltip 中写明状态。
- 图表 Tooltip 避让容器四边并通过 Portal 展示，不得被 overflow:hidden 裁切。
- 图片加载失败使用统一占位；内容图 alt 描述“设备/位置/证据类型”，装饰图 alt 为空。

## 2.8 浮层层级与动画

统一 z-index：

| 层 | z-index |
|---|---:|
| 页面普通内容 | 0 |
| 粘性表头/面板控件 | 10 |
| 左侧栏/顶栏 | 100/110 |
| 下拉、Tooltip、右键菜单 | 200 |
| 移动遮罩/抽屉 | 250/260 |
| 模态遮罩/弹窗 | 300/310 |
| 全局通知/Toast | 400 |
| 阻断任务进度 | 450 |

过渡统一：

- Hover/按压：120ms。
- Tab、面板收起、工作区移动：160～180ms。
- 弹窗、抽屉：240ms，cubic-bezier(.2,0,0,1)。
- 下拉：opacity 0→1、translateY(-4px)→0。
- 弹窗：遮罩淡入；容器 opacity 0→1、scale(.98)→1。
- 右侧抽屉：translateX(100%)→0。
- Toast：右移 12px 且透明→原位，180ms ease-out；关闭反向 140ms。
- prefers-reduced-motion: reduce 时取消位移、缩放、自动滚动和装饰性循环，仅保留即时显隐；旋转器可用静态省略号替代。

## 2.9 PC 自适应与可访问性验收

- 核心生产工作台支持 1366×768 及以上。1280×720 允许工作台内部横向滚动；≤900px 只保证全局导航和异常页可用，不承诺业务工作台移动重排。
- 验收必须覆盖浏览器缩放 100%、125%、150%、200%；200% 下焦点项不得完全被裁切，弹窗必须可滚动到操作按钮。
- 所有鼠标操作必须有键盘路径；Tab 顺序按视觉顺序，Enter/Space 激活按钮，Esc 按第 6 章关闭浮层。
- 标注矩形必须提供键盘选中、箭头移动 1%、Shift+箭头移动 5%、Alt+箭头调整尺寸，并朗读归一化位置和尺寸。
- 点击目标最小 24×24px；常规桌面操作建议 36px，触摸入口 44px。
- 状态点、曲线颜色和告警颜色不得作为唯一信息；必须有文本/图例。
