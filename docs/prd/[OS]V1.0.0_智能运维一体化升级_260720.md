## 一、需求背景

当前工业现场的视频监控、音视频分析、采集站配置和算法管理能力分散在不同工具中。值班员、运维工程师和算法工程师需要在多个系统之间切换，设备上下文、报警信息和分析结果难以连续传递，带来以下核心问题：

1. 设备、采集站、测点和报警缺少统一入口，日常操作链路长。
2. 视频监控、报警处置与音视频趋势分析相互割裂，异常定位效率低。
3. RH830 采集站的网络、设备关联、算法绑定、参数和标注区域配置缺少完整、可演示的前端闭环。
4. 页面信息密度、交互规则和状态反馈不统一，学习成本高，异常操作风险大。
5. 当前阶段尚未接入完整后端服务，需要一个使用模拟数据也能完整演示的前端版本，用于试点验证、需求评审和接口联调。

因此，本次迭代将在智能运维 OS 中统一建设“智慧视频监控”“采集站管理”和“音视频分析”三个业务模块，形成从设备发现、实时监控、报警判断到分析与配置的连续工作流，并为后续真实设备、流媒体、报警、算法和时序数据服务接入提供稳定的产品与前端基线。

### 1.1 目标用户

| 用户角色 | 核心诉求 | 典型任务 |
| --- | --- | --- |
| 值班员 | 快速掌握设备与报警状态 | 查看实时画面、确认报警、关闭报警、转缺陷 |
| 运维工程师 | 定位设备和采集异常 | 搜索设备、云台控制、录像回放、自检、重启 |
| 算法工程师 | 配置并验证监测算法 | 绑定测点和功能、编辑参数、维护标注区域 |
| 管理人员 | 了解风险与处置效率 | 查看报警统计、完成率和重点异常 |
| 系统管理员 | 维护采集站及系统参数 | 配置网络/代理、关联设备、下载配置和日志 |

- 不替代专业 NVR、视频编辑器、缺陷管理系统或算法训练平台。
- 不在音视频分析模块中提供单趋势、多趋势等非音视频专属工具。

## 二、产品原则与方案取舍

本期没有可验证的外部竞品研究材料，因此不输出未经证据支撑的竞品结论。评审统一使用以下产品原则判断方案是否符合目标；后续如补充竞品体验，应附产品版本、截图、体验路径与观察日期。

| 原则 | 本期选择 | 明确不做 | 判断标准 |
| --- | --- | --- | --- |
| 上下文连续 | 监控、采集站和分析之间支持带参跳转 | 仅提供彼此独立的功能入口 | 跳转后保留设备/测点/时间上下文 |
| 专业密度优先 | 保留树、表格、图表和紧凑配置工作区 | 用大卡片或装饰性看板替代诊断工作台 | 1440×900 下关键数据与操作无需频繁滚动 |
| 风险可控 | 写操作有校验、确认、进度、结果和审计 | 静默覆盖、无反馈提交或不可恢复删除 | 高风险操作可解释、可追踪、不重复提交 |
| 原型可独立验证 | 用模拟数据覆盖主链路和异常状态 | 将“等待后端”作为交互缺失理由 | 断开后端仍能完成全部 P0/P1 用例 |
| 兼容演进 | 已有绑定锁定并合并新增配置 | 覆盖存量绑定或重新生成稳定 ID | 存量数据升级后语义与标识保持稳定 |

核心差异化：围绕同一设备和测点上下文，形成“发现异常 → 查看证据 → 分析定位 → 调整配置 → 获得结果”的一体化运维链路。

### 3.2 体验目标

- 保持浅色、紧凑、企业级的智能运维 OS 视觉体系。
- 视频画面、趋势图和配置表单优先获得可用空间。
- 所有写操作均提供加载、成功、失败和防重复提交反馈。
- 删除、重启、关闭报警等高风险操作必须二次确认。
- 页面在 1440×900 及以上常用工作站尺寸下不得出现关键操作遮挡。

### 3.3 验收总则

- P0：无白屏、死循环、未捕获运行时错误和关键资源缺失。

- P2：搜索、筛选、空数据、失败、禁用、二次确认和键盘访问状态完整。

### 3.4 需求表达与追踪规则

- 范围编号使用 `S-*`，全局需求使用 `OS-*`，视频监控使用 `V-*`，采集站使用 `R-*`，音视频分析使用 `A-*`。

- 原型模拟与生产实现有差异时，正文需明确写出两者边界，不得将模拟成功等同于真实服务已接入。

## 五、具体设计

### 5.1 OS 全局框架

#### 5.1.1 导航与工作区

页面由顶部栏、主导航、页签栏和业务工作区组成。顶部栏负责产品身份、通知和用户入口；主导航只承担一级模块切换；页签栏表达当前打开页面；业务工作区由各模块自行管理。

| 区域 | 默认内容 | 交互规则 |
| --- | --- | --- |
| 顶部栏 | 应用切换入口、产品标识“智能运维 OS”、通知、当前账号 | 通知和账号浮层互斥；点击浮层外关闭；移动端保留菜单、通知和账号入口 |
| 主导航 | 首页、智慧视频监控、采集站管理、音视频分析 | 当前模块同时使用图标、文字和背景表达选中态；模块顺序固定，不因权限缺失而重排 |
| 页签栏 | 主页页签、当前业务页签 | 当前页签高亮；业务页签可关闭；主页不可关闭；关闭当前业务页签后返回主页 |
| 工作区 | 当前模块页面 | 模块切换时先完成未保存检查；内容填满剩余宽高，不预留收起侧栏的空白 |

桌面端侧栏默认展开，默认宽度 280px，可拖动范围 220～480px；拖动时显示列宽变化且不选中文本，双击拖动条恢复 280px。宽度保存在当前浏览器，刷新后恢复；若保存值超出范围则回退默认值。

点击“收起侧栏”后，侧栏必须完全移出屏幕，不保留图标窄栏；工作区扩展到左边缘。左下角保留固定、可聚焦、不会遮挡主要操作的恢复按钮。隐藏侧栏及拖动条不得继续接收键盘焦点。

移动端使用覆盖式抽屉：打开时显示遮罩并锁定页面横向滚动，点击遮罩、关闭按钮或选择导航项后收起；关闭后焦点回到菜单按钮。

#### 5.1.2 页签与路由

- 路由固定为：主页 `/`、智慧视频监控 `/video-monitoring`、采集站管理 `/collection-stations`、音视频分析 `/audio-video-analysis`；静态部署使用对应 Hash 路由。
- 首次进入业务路由时创建业务页签；重复进入只激活已有页签，不产生重复项。
- URL 是页面状态的最终来源。地址变化、浏览器前进/后退、手动修改 Hash 后，页面、页签和导航选中态必须在同一渲染周期内同步。
- 关闭当前业务页签后跳转主页；关闭非当前页签不改变当前页面。存在未保存修改时，关闭前执行统一离开确认。
- 业务内需要分享的关键上下文使用查询参数传递，例如设备、站点、测点和时间范围；纯 UI 偏好（侧栏宽度、折叠状态）存储在本地，不写入 URL。
- 无效路由显示可返回主页的 404 状态，不得静默白屏；缺失或无效参数回退模块默认值，并使用轻提示说明。

#### 5.1.3 全局反馈

| 场景 | 展现方式 | 行为要求 |
| --- | --- | --- |
| 轻量成功/提示 | Toast | 默认 2～4 秒自动消失；同一操作只展示一条；不得遮挡主要按钮 |
| 表单校验失败 | 字段内错误 + 页级提示 | 聚焦并滚动到首个错误字段；保留用户输入；修正后即时清除对应错误 |
| 页面读取中 | 骨架屏或区域加载层 | 保留稳定布局，避免内容跳动；不可操作区域设为忙碌态 |
| 写操作处理中 | 按钮加载态 + 禁止重复提交 | 按钮文案表达当前阶段，如“校验中”“保存中”“下发中”；不得仅显示转圈 |
| 高风险操作 | 模态确认 | 标题使用具体动作；正文展示对象和影响；危险按钮使用动作文案，不使用笼统“确定” |
| 长任务 | 进度/阶段反馈 | 显示当前阶段、结果与失败原因；允许安全取消或失败重试时提供入口 |

通用页面状态包括初始、加载、成功、空数据、失败、无权限、离线和数据过期。空数据需要区分“没有数据”和“筛选无结果”；失败状态保留当前筛选条件；数据过期状态展示最后更新时间并允许刷新。

删除数据组/功能、重启设备、关闭报警、转缺陷、移除设备关联、参数下发等操作必须二次确认。确认期间若对象状态已变化，提交时以后端最新状态为准，并提示用户刷新结果。

配置页面统一维护 `clean → dirty → saving → saved/error/conflict` 状态：首次编辑进入 `dirty`；保存中锁定重复提交；成功后更新数据版本和保存时间；失败保留修改；版本冲突禁止覆盖并提供“重新加载”和“复制本次修改”处理入口。

#### 5.1.4 全局验收用例

| 用例 | 优先级 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| OS-01 导航与路由一致 | P0 | 已进入任一业务模块 | 刷新页面并执行浏览器前进/后退 | 页面、URL、页签和导航选中态始终一致，无 404/白屏 |
| OS-02 侧栏完全收起 | P1 | 桌面端侧栏已展开 | 点击收起，再点击恢复 | 侧栏完全移出；工作区扩展到左边缘；恢复按钮始终可见；恢复后宽度与导航能力正常 |
| OS-03 未保存保护 | P1 | 任一配置表单存在未保存修改 | 切换站点、关闭页签或刷新 | 出现保存/放弃提示；取消后保留原状态；不得静默丢失修改 |
| OS-04 防重复提交 | P1 | 写操作可提交 | 连续点击提交按钮 | 仅产生一次业务操作；按钮显示处理中；完成后展示明确结果 |
| OS-05 通用异常状态 | P2 | 模拟无权限、离线或请求失败 | 进入对应页面或重试 | 状态原因清晰、可恢复时提供重试、不可用操作处于禁用态 |

### 5.2 智慧视频监控

#### 5.2.1 页面结构

页面采用固定诊断工作台，不使用首页式指标卡布局。

| 区域 | 建议宽度 | 内容 | 约束 |
| --- | --- | --- | --- |
| 左侧设备区 | 220～280px | 搜索、设备统计、多级设备树 | 右栏展开时不得被压缩；树内容独立滚动 |
| 中间视频区 | 剩余宽度 | 视频墙、轮播/分页/分屏工具栏 | 页面主要内容区；优先保障画面面积 |
| 右侧功能区 | 300～360px | “报警看护”“云台与回放”两个模式 | 展开后作为独立网格列，只压缩中间视频区，不覆盖画面 |

默认进入后：加载设备树 → 恢复上次选择；无历史选择时选中前 4 路在线摄像机 → 使用四画面布局 → 第一块有效画面成为当前控制设备 → 右栏默认显示报警看护。任一数据读取失败不得阻止其他区域加载。

1500px 及以下桌面宽度，设备区至少保持 220px；工具栏可以隐藏“秒”“当前页”等冗余说明并缩小间距，但轮播、分页、分屏和右栏恢复入口必须保留。右栏收起后在边缘显示恢复按钮和待处理报警数量徽标。

#### 5.2.2 设备树

设备层级固定为站点 → 区域/廊道 → 文件夹（可选）→ 摄像机。每个节点显示名称；摄像机同时显示在线状态，名称过长时单行省略并在悬停/聚焦时显示完整内容。

| 操作 | 规则 |
| --- | --- |
| 展开/收起 | 点击箭头只改变展开状态，不改变勾选；搜索命中深层节点时自动展开祖先 |
| 搜索 | 按名称或编码模糊匹配；过滤只改变可见节点，不取消原选择；无结果显示关键词和清空入口 |
| 摄像机选择 | 勾选后加入视频数据源；取消后移除；选择变化时重新计算分页并尽量保持当前设备可见 |
| 父级选择 | 勾选父级时选择其全部后代摄像机；取消时清空后代；部分选中使用半选状态 |
| 行激活 | 点击摄像机名称将其设为当前控制设备；未勾选时同时加入选择并定位到包含该设备的页 |
| 状态统计 | 总数/在线/离线基于完整设备树计算，不随搜索结果缩减；第三方能力受限单独标识并计入总数 |

设备状态至少包括在线、离线、连接中和第三方/能力受限。状态更新不得清空用户选择：在线变离线后保留槽位并展示离线状态；重新在线后尝试恢复播放。展开状态、选择状态和当前设备可保存在浏览器，后续生产版本改由用户偏好服务保存。

#### 5.2.3 实时视频墙

每个视频槽位包含摄像机名称/编码、状态标识、画面、采集时间、当前控制标识和悬浮控制条。空槽位只展示占位说明，不展示无效控制。

| 能力 | 详细规则 |
| --- | --- |
| 分屏 | 支持 1/4/9 画面；切换后 `总页数 = ceil(已选设备数 / 槽位数)`；当前页超界时回到最后有效页 |
| 分页 | 上一页/下一页在边界禁用；页码变化只建立当前页所需流连接，离页流及时释放 |
| 轮播 | 间隔限制 1～60 秒；多页时按页轮播，单页多设备时按槽位顺序激活当前设备；手动翻页后从新页重新计时 |
| 暂停轮播 | 用户点击暂停、页面不可见、视频墙获得键盘焦点或打开弹窗时暂停；恢复后不补跳过的页 |
| 单路控制 | 播放/暂停、静音/取消静音、单路全屏、抓拍、重连和更多操作只影响当前槽位 |
| 画质 | 高清/流畅为墙级默认值；切换后逐路请求，不因单路失败回滚其他成功画面 |
| 当前控制 | 点击画面设置为当前设备，并联动右侧云台和回放；选中边框与“当前控制”文字同时出现 |

画面状态流转为 `空槽位 → 加载中 → 播放中 ↔ 暂停`；网络异常进入 `重连中 → 播放中/失败`；设备离线进入 `离线` 并保留最后有效画面和更新时间。失败状态展示原因与“重新连接”，单路错误不得覆盖整墙。

整体全屏时保留分屏、分页、轮播和退出全屏入口；按 Escape 退出后焦点回到触发按钮。视频图像只作为证据展示，不在前端暴露真实流地址或鉴权信息。

#### 5.2.4 云台与录像回放

右栏“云台与回放”模式始终使用当前控制设备作为上下文；设备切换后取消未完成的旧设备查询和临时控制状态，再加载新设备能力与录像列表。

云台能力按设备 `capabilities` 动态呈现：

- 方向控制支持上、下、左、右和中心复位。生产实现按“按下开始、释放停止”发送连续控制指令；键盘触发使用短步进指令。
- 调焦、聚焦和光圈支持增/减，显示当前执行动作；同一控制组执行中暂时禁用相反指令。
- 对讲、补光、雨刷和录像为可切换状态，界面同时展示动作结果与当前状态；刷新后以后端状态为准。
- 重启属于高风险操作，确认弹窗展示设备名称和预计中断影响；提交成功表示“指令已受理”，不等同于设备已重启完成。
- 未选择、离线、执行中或能力不支持时按钮禁用，并展示具体原因；第三方设备不得假设具备云台能力。

录像回放默认查询当前设备最近记录，支持以下筛选和字段：

| 项目 | 内容 |
| --- | --- |
| 来源 | 上位机、下位机；设备不支持双来源时隐藏来源页签 |
| 筛选 | 录像方式、开始/结束时间；开始时间不得晚于结束时间 |
| 排序 | 默认按开始时间倒序，可切换升序 |
| 表格字段 | 录像名称、开始时间、结束时间、时长、录像方式、操作 |
| 列设置 | 可隐藏非关键列；录像名称、开始时间和操作不可隐藏 |
| 分页 | 切换设备、来源或筛选条件后回到第 1 页；空结果保留查询条件 |

点击“回放”打开模态播放器，支持播放/暂停、进度拖动、倍速切换和关闭。打开时锁定背景滚动并暂停报警/视频轮播；关闭后恢复焦点及此前轮播状态。回放地址失效时可重新获取签名地址，不清空列表选择。

#### 5.2.5 报警看护

右栏默认显示“报警看护”，上部为今日统计，下部为最近报警。统计卡包含今日新增、今日处理、今日转缺陷、待处理和完成率；点击待处理、今日处理或转缺陷统计可切换下方筛选。完成率按 5.7.1 统一口径计算。

报警列表默认按报警时间倒序，支持全部、待处理、已处理和已转缺陷筛选。卡片展示缩略证据、标题、等级、状态、时间和设备路径；等级至少支持 1～4 级，状态文字与颜色共同表达。

最近报警可自动轮播，鼠标悬停、键盘聚焦、滚动列表或打开详情时暂停。轮播只改变当前高亮卡片，不自动改变摄像机选择；用户执行“定位设备”后才切换视频与当前控制设备。

报警详情展示：报警编号、标题、等级、状态、发生时间、设备路径、图片/视频附件、处置记录和缺陷编号。多附件支持前后切换；视频附件支持播放/暂停；附件加载失败不阻止查看文本信息。

报警状态机：

```text
待处理 ──关闭报警──> 已关闭
   └────转为缺陷──> 已转缺陷（必须返回 defectId）
```

- 仅“待处理”允许首次转缺陷；已转缺陷不得重复创建缺陷。
- 已关闭报警不可再次关闭；若业务允许重新打开，应作为后续独立需求，不在本期默认提供。
- 关闭和转缺陷均二次确认。提交中锁定两个处置按钮；失败时保留详情与原状态并显示原因。
- 成功后使用接口返回的最新报警更新统计、筛选计数、列表和详情，不通过前端猜测状态；若当前筛选不再包含该报警，则关闭详情并提示其新状态。

### 5.3 采集站管理（RH830）

#### 5.3.1 采集站选择

页面由采集站树、密集配置头部、一级/二级页签和配置正文组成。采集站树可独立隐藏，隐藏后正文占用释放空间；恢复按钮保留在树与正文边界。

左侧顶部提供“采集站编码”和“采集站名称”两个独立模糊筛选，条件采用 AND 关系。每行固定展示编码、名称和在线/离线状态，名称溢出时可查看全称；筛选无结果时保留条件并提供清空入口。

选中站点后按以下顺序加载：基本元数据 → 关联设备 → 当前页签配置 → 算法绑定/可见光资源。头部持续展示站点类型、名称、模型、模型版本和 IP，避免用户在深层配置时丢失上下文。局部加载失败只影响对应区域，并显示重试。

切换站点的规则：

1. 当前状态为 `clean` 时立即切换，并恢复新站点上次访问的配置页签。
2. 存在未保存修改时弹出“保存并切换 / 放弃修改 / 取消”三选项。
3. “保存并切换”仅在保存成功后执行切换；失败则停留原站点并保留修改。
4. “放弃修改”重新加载原站点数据后切换；不得把原站点临时状态带到新站点。
5. 通过顶部下拉或左侧列表切换站点执行同一规则。

#### 5.3.2 属性/基本信息

“属性”一级页签内部使用基本信息、网络信息、自检信息三个纵向子项。该一级页签没有顶部二级页签行，正文必须直接填满页签下方剩余高度。

基本信息严格按以下顺序展示 6 项，不新增统计卡或改变为卡片瀑布流：

| 序号 | 字段 |
| --- | --- |
| 1 | 采集站编码 |
| 2 | 物设备模型 |
| 3 | 物设备模型版本 |
| 4 | 算法版本 |
| 5 | 架构版本 |
| 6 | 温补温控库硬件版本 |

基本信息后显示可折叠“板信息”。表格固定为序号、卡槽、板类型、软件版本、硬件版本、序列号、传感器类型、通道 8 列，默认展示核心板和辅助板 2 条记录；字段暂无数据时显示 `--`，不使用空白单元格造成误解。板信息后依次展示采集站同步类型和最大通道数。

网络信息展示 IP、子网掩码、默认网关、首选 DNS、连接状态和最后更新时间，并提供“编辑网络参数”。自检信息展示最近自检时间、检查项、结果与说明；至少覆盖核心板通信、视频流、存储空间和算法服务。单项异常不应隐藏其他检查结果。

#### 5.3.3 配置与设备关联

配置头部固定提供预览调试、代理配置、重启、设置网络参数、下达参数、更多和保存。高频“保存”始终可见；导出配置、下载日志收纳在“更多”中。正文一级页签为板卡集合、属性、常规采集策略；板卡集合二级页签为视频设置、补光设置、清洁设置、算法标注、算法参数、定时重启。

配置字段与校验：

| 配置 | 字段 | 校验/联动 |
| --- | --- | --- |
| 网络参数 | IP、子网掩码、默认网关、首选 DNS | 必须为合法 IPv4；IP 与网关需处于有效网段；保存前提示网络变更可能导致短暂离线 |
| 代理配置 | 启用、协议、地址、端口、用户名、密码 | 协议支持 HTTP/HTTPS/SOCKS5；端口 1～65535；关闭代理时地址和凭证不作为必填；密码读取时不回显明文 |
| 常规采集策略 | 声音偏量、调试日期、调试周期 | 数值字段必须为有限数字；周期必须大于 0；单位和说明始终与输入同列展示 |
| 视频设置 | 分辨率、帧率、码率、默认码流 | 分辨率为枚举；帧率 1～25 FPS；码率大于 0；默认码流为主码流/子码流 |
| 补光设置 | 补光使能、工作模式、亮度 | 模式为自动/常亮/常灭；亮度 10%～100%；关闭使能后亮度不可编辑但保留原值 |
| 清洁设置 | 自动清洁、清灰周期、单次时长 | 开启后周期和时长必填且大于 0；关闭后计划不执行但保留配置 |
| 算法参数 | 图片质量阈值、报警/异常/正常回传上限 | 阈值和上限不得为负；上限单位为条/天；具体生产范围由 RH830 协议冻结 |
| 定时重启 | 使能、周期、小时、分钟 | 周期 ≥1 天，小时 0～23，分钟 0～59；关闭后不执行计划 |

弹窗内“确定”只更新页面草稿并进入未保存状态，右上角“保存”才提交平台配置。保存成功后展示保存时间和最新数据版本；保存失败保留草稿。点击“下达参数”时若存在未保存修改，必须明确告知将先保存再下达；保存失败则终止下达。下达成功以采集站确认结果为准，不以请求发出作为最终成功。

关联设备弹窗支持按设备名称模糊搜索和多选，已关联设备默认选中。确认后更新草稿，并即时刷新算法绑定的数据 ID 候选。移除设备前检查依赖：若设备或后代测点仍被绑定，阻止移除并列出数据组和功能；无依赖时二次确认后移除。

预览调试展示可见光画面、视频状态、分辨率、帧率、延迟和已分析帧数，支持开始/停止分析与截取快照。重启、自检、保存、下达和下载均展示进行中、成功、失败与重试反馈。文件名统一为 `RH830-{stationCode}-{type}-{yyyyMMddHHmmss}.{ext}`，导出配置必须脱敏代理密码。

#### 5.3.4 算法绑定

算法标注是本期唯一显著扩展的配置页签，采用“左侧绑定与功能卡片 + 右侧可见光预览”的双栏工作区。页签顶部提供数据 ID 单选、监测功能级联多选和“绑定”动作。

数据 ID 候选只包含当前站点已关联设备及其后代测点，搜索匹配设备名称、测点名称和完整路径。候选行显示类型与路径；已经形成数据组的候选标记“已绑定”，但仍允许选中以追加功能。切换数据 ID 后加载该数据组已有功能。

监测功能按业务分组级联多选，至少展示分组、功能名称、选中状态和已有绑定状态。已有功能保持选中且锁定，用户不能通过选择器取消；只有在对应功能卡片执行删除才能解除。未选择数据 ID 或未选择任何新增功能时，“绑定”禁用并说明原因。

绑定合并算法：

1. 提交时按 `dataId + functionId` 去重。
2. 数据组不存在时，在列表末尾创建新组；已存在时保留组位置和展开状态。
3. 已有功能的参数、颜色、区域、描述、显隐和 `createdAt` 全部保留。
4. 新增功能按本次选择顺序生成 `createdAt`，追加在已有功能之后。
5. 若接口返回部分成功，成功项进入列表，失败项保留在选择器并逐项展示原因。

每个数据组头部展示数据名称、完整路径、功能数量、折叠状态和删除入口。每张功能卡展示功能名、参数摘要、标注区域数量/无需标注、标注颜色、监测位置描述及显隐状态。点击卡片后设为当前功能，并驱动右侧画面叠加对应标注。

- 参数编辑：按属性、值、单位展示；数值类型执行必填、格式和范围校验；弹窗保存后更新卡片摘要并标记页面未保存。
- 位置描述：可选；为空时报警位置回退测点名称；去除首尾空格并限制生产接口定义的最大长度。
- 标注显隐：仅影响当前功能的预览和保存字段，不删除区域。
- 颜色修改：功能默认颜色变化时同步更新未单独覆盖颜色的区域；颜色值按十六进制保存。
- 删除功能：二次确认并说明影响；删除组内最后一个功能等同删除数据组。
- 删除数据组：二次确认并列出功能数量；只删除该数据 ID 下的绑定，不解除监测设备关联。

所有新增、编辑、删除均先进入页面草稿，统一通过右上角“保存”提交；“下达参数”将已保存的最新绑定发送至站点。

#### 5.3.5 可见光标注

右侧预览以当前采集站可见光图像为底图，顶部显示“可见光”和当前功能。未选择功能时展示引导，不显示其他功能区域；选择功能后只叠加该功能的可见区域，避免多个算法标注混杂。

工具栏左侧优先放置“截取快照”，其后依次为全屏/恢复、标注工具、放大、缩小、复位、显示/隐藏全部标注和锁定/解锁。缩放范围建议 80%～150%，复位恢复 100% 和画面中心；锁定状态下禁止误拖区域但允许查看和缩放。

标注编辑弹窗采用“图像画布 + 区域列表”结构。区域模型至少包含 `regionId`、名称、颜色、形状、归一化坐标、可见状态和顺序。

| 操作 | 规则 |
| --- | --- |
| 新增区域 | 默认命名“标注区域 N”，使用功能默认颜色；名称在当前功能内不可重复 |
| 选择区域 | 画布框和列表行双向高亮；列表滚动时不改变选择 |
| 重命名 | 去除首尾空格；空名称和重复名称禁止保存 |
| 调整范围 | 生产版支持拖动与缩放；区域不得完全移出图像边界，最小尺寸由设计/算法共同确认 |
| 修改颜色 | 区域框、标签和列表色块立即同步；颜色不承载唯一识别信息 |
| 删除区域 | 二次确认；删除后重新选择相邻区域；不自动关闭弹窗 |
| 显示/隐藏 | 只切换预览可见性，不删除坐标；功能卡显隐优先级高于区域显隐 |

区域坐标统一存储为相对原图宽高的归一化值，避免分辨率变化导致偏移；生产接口需携带原图尺寸和坐标版本。原型阶段允许固定框演示，但必须完整演示新增、删除、重命名、颜色和显隐状态。

支持明确的“该功能无需标注区域”状态：启用后清空或停用区域前必须确认；界面不显示空区域错误；该状态与“尚未配置区域”含义不同，保存字段也必须区分。

### 5.4 音视频分析

#### 5.4.1 页面结构

沿用“通用分析”的高密度诊断工作台，不改造成数据看板或大尺寸媒体预览页。页面固定为三栏：

| 区域 | 默认内容 | 详细规则 |
| --- | --- | --- |
| 左侧资源区 | 名称/编码搜索、设备/测点树 | 音频和视频测点使用不同图标；只显示可用于音视频分析的测点；独立滚动 |
| 中间分析区 | 工具条、完整路径、现场附件、同步趋势图 | 图表是主内容；附件位于图表左侧且当前点有图像时默认展开 |
| 右侧操作区 | 时间范围、节点、指标、数据列表、重置/确定 | 可拖动调宽 224～380px，默认 260px；双击恢复默认；方向键每次调整 16px |

右侧调宽时中间图表实时自适应，不遮挡、不溢出。拖动条支持鼠标、触控笔和键盘，使用 `Home/End` 到最小/最大宽度。浏览器刷新后可恢复用户上次宽度；超出可用空间时回退默认值。

顶部工具区只提供“音视频通用分析”，可以收藏为常用工具。模块内不得出现单趋势、多趋势或其他与音视频无关的分析工具入口。

#### 5.4.2 查询与指标

首次进入模块选择产品预设的默认测点，查询结束日期为当前站点日期，开始日期为包含结束日在内的最近 15 天，并自动执行一次查询。页面需要区分“当前编辑条件”和“上次已执行条件”：用户修改日期或指标后，图表继续显示上次结果，直到点击“确定”，同时用轻量状态提示“条件已修改，待查询”。

查询字段和校验：

| 字段 | 默认值 | 规则 |
| --- | --- | --- |
| 开始日期 | 结束日期向前 14 天 | 必填，不得晚于结束日期 |
| 结束日期 | 当前站点日期 | 必填；是否允许未来时间由数据服务决定，本期默认不允许 |
| 节点 | 默认音视频测点 | 必选；通过左侧树切换，右栏仅展示当前选择摘要 |
| 指标 | 当前测点全部兼容指标 | 至少选择 1 项；按视觉算法、音频算法等业务分组 |

单次查询采用闭区间，包含首尾日期，最大跨度 30 天。校验顺序为必填 → 起止关系 → 跨度 → 指标数量；失败时不发起请求、不清空旧结果，并将焦点定位到问题字段。

点击“确定”后锁定条件控件和按钮，显示“查询中”及分析区域加载层。成功后原子更新图表、数据列表、阈值、附件和查询时间；失败保留旧结果并提示“数据仍为上次查询结果”。“重置”恢复当前测点的默认 15 天和全选指标，并重新执行默认查询。

切换测点时取消前一测点未完成请求，加载新测点的兼容指标、默认样本和附件类型，清除仅属于旧测点的标注、误信号与折叠状态。视频测点只展示视觉兼容指标和图片/视频附件；音频测点只展示音频兼容指标和音频/波形附件。

指标按组展示，组内默认全选。取消全部指标时图表显示“请至少选择一个分析指标”，点击“确定”阻止提交。图表布局按可见指标数量自适应：1 个图表填满主要高度，2 个图表平均分配，其余使用紧凑同步列表并允许纵向滚动。

#### 5.4.3 图表、数据和附件

每个指标独立显示标题、当前选中值、单位、趋势图、Y 轴口径和折叠按钮；多个指标共享相同 X 轴时间范围和选中时间。图表折叠只隐藏该指标绘图区，不取消指标选择或样本选择。

趋势点视觉语义固定如下：

| 状态 | 图形表达 | 说明 |
| --- | --- | --- |
| 无附件、正常 | 蓝色描边空心点 | 仅有时序数据 |
| 有附件、正常 | 蓝色实心点 | 点击后可查看图片、视频或波形 |
| 报警 | 红色实心点 + 状态文字 | 由该指标自身阈值计算，不继承同时间其他指标状态 |
| 当前选中 | 外圈/引导线 + 加粗 | 可与上述三种基础状态叠加 |
| 误信号 | 独立标记或淡化 | 保留原始值；开启误信号筛选后可隐藏，不改写报警原值 |

悬停或键盘移动到趋势点时展示毫秒级时间戳、格式化值、单位、附件状态和报警状态。点击后将该点作为全局选中样本：所有图表同步游标到相同时间；右侧数据列表定位对应行；现场附件切换至该样本；报警点同时展示阈值/规则、报警描述和处置上下文。

报警判断必须以 `metricId + thresholdVersion + sampleValue` 独立计算。离散指标按自身枚举规则判断，连续指标按上/下限判断；缺失阈值时显示“阈值未配置”且不标红。数据源明确返回“运行正常”时不得因同时间其他指标、附件或整行状态标红。页面不得展示已移除的独立文案“2026-07-20 14:26:18 / 报警依据：跑偏20cm”。

右侧数据列表默认展示当前指标最新 8 条，字段为采样时间、值和状态；生产数据超过可视数量时滚动或分页。点击行与点击趋势点等效；状态图标区分无附件、有附件和报警，并提供文字提示，不能只靠颜色。

现场附件遵循当前选中样本：

- 图片：默认展开，支持原图/全屏查看；加载失败显示文件信息与重试。
- 视频：展示封面、时长和播放/暂停；切换样本时停止上一附件播放。
- 音频/波形：提供播放、暂停和“关联波形分析”；切换样本时重置进度。
- 多附件：显示序号与总数，支持前后切换；附件切换不改变趋势点。
- 无附件：展示明确空状态，不折叠整个附件区域。

用户可折叠附件区域以扩大图表，但折叠不丢失样本、附件序号和播放前上下文；点击新的有附件点时默认自动展开。

#### 5.4.4 分析工具

工具栏提供高频操作，右键菜单提供完整上下文操作；两处相同能力共享同一状态，不得出现工具栏已开启、右键菜单仍显示旧状态的情况。

| 工具 | 作用对象 | 结果 |
| --- | --- | --- |
| 动态游标 | 当前所有可见图表 | 开启后图表共享时间游标；关闭后保留当前选中点 |
| 恢复缩放 | 当前分析结果 | 恢复全部图表默认时间范围和比例，不重新查询数据 |
| 标注 | 当前样本 | 添加/移除本地分析标记；标记与指标和时间绑定 |
| 报警线 | 当前指标或全部指标 | 显示当前生效阈值线；缺少阈值时提示不可添加 |
| 设置误信号 | 当前样本 | 标记或取消误信号，必须记录操作者和原因；原始数据不删除 |
| 误信号筛选 | 当前结果集 | 显示/隐藏已标记误信号，并明确当前筛选状态 |
| 界面设置 | 当前用户 | 控制游标、报警线、误信号筛选等显示偏好 |
| 导出单图 | 当前指标 | 导出包含标题、时间范围、单位、阈值和图例的图形文件 |
| 导出全部数据 | 当前查询结果 | 导出查询条件、测点、指标、毫秒时间、值、单位、附件、报警和处置状态 |
| 关联波形分析 | 当前音频样本 | 有波形时打开分析弹窗，无波形时明确提示 |
| 全屏 | 整个分析工作台 | 保留树、图表、附件和操作区；Escape 退出并恢复焦点 |

右键菜单在视口边缘自动调整位置，打开时将右键所在指标和时间设为当前上下文。执行后关闭菜单并通过画面状态或提示反馈结果；不可执行项禁用并说明原因。

波形分析弹窗展示样本时间、播放控制、波形、选区和基础统计（时长、峰值、均值或业务确认的指标），支持导出选区。关闭弹窗后返回原趋势点，不改变查询条件。

导出文件使用 UTF-8，文件名包含测点、查询结束时间和导出类型；导出操作在无指标、无数据或浏览器拒绝下载时给出明确失败提示。

### 5.5 跨模块联动

跨模块跳转使用稳定 ID 与时间参数，不使用展示名称作为唯一定位依据。

| 来源动作 | 目标路由 | 携带参数 | 目标模块行为 | 异常处理 |
| --- | --- | --- | --- | --- |
| 采集站关联设备“查看监控” | `/video-monitoring` | `stationCode`、`deviceId` | 展开设备祖先、勾选并激活目标摄像机，定位到包含该设备的页 | 无权限时保留来源页；设备不存在时进入模块并提示已失效 |
| 报警详情“进入音视频分析” | `/audio-video-analysis` | `deviceId`、`pointId`、`alarmId`、`startTime`、`endTime` | 选择测点、带入报警前后时间窗并自动查询，选中最接近报警时刻的样本 | 无匹配测点时保留时间并提示用户手动选择 |
| 音视频报警点“查看监控证据” | `/video-monitoring` 或附件弹窗 | `deviceId`、`sampleTime`、`attachmentId` | 优先打开附件；无附件时查询覆盖样本时间的录像 | 签名地址过期时重新获取；无录像时保留分析上下文 |
| 报警“转为缺陷” | 外部缺陷详情（后续） | `defectId` | 本期仅展示并复制缺陷编号；未来支持受控跳转 | 创建失败保持待处理，不生成本地虚假编号 |

时间参数统一使用带时区 ISO 8601，跳转时间窗默认取事件前后各 5 分钟，若超出音视频分析 30 天限制则裁剪并提示。目标页面完成参数解析后才更新 URL 状态；无效参数不得导致白屏。

跨模块跳转前同样执行未保存检查。用户取消离开后，来源页面的弹窗、滚动位置和当前对象保持不变。

### 5.6 核心流程

```text
进入 OS
  ├─ 智慧视频监控 → 选择设备 → 查看画面/报警 → 回放或处置
  ├─ 采集站管理 → 选择站点 → 配置/关联设备 → 绑定算法 → 参数与标注 → 保存
  └─ 音视频分析 → 选择测点 → 设置时间与指标 → 查询 → 点选异常 → 查看附件/波形 → 导出
```

#### 5.6.1 视频报警处置流程

```text
进入模块
  → 恢复设备选择并加载视频墙
  → 查看待处理报警
  → 打开详情与证据
  ├─ 定位设备 → 激活画面 → 查看实时/回放
  ├─ 关闭报警 → 二次确认 → 更新统计、列表与详情
  └─ 转为缺陷 → 二次确认 → 创建成功并展示 defectId
                         └─ 失败：保留待处理状态与详情，可安全重试
```

#### 5.6.2 RH830 配置与下发流程

```text
选择站点
  → 查看属性和当前配置
  → 编辑网络/策略/设备关联/算法绑定/标注
  → 页面进入未保存状态
  → 保存前统一校验
  ├─ 校验失败：定位首个字段，保留全部草稿
  ├─ 版本冲突：禁止覆盖，重新加载或复制本次修改
  └─ 保存成功：更新版本和保存时间
       → 下达参数 → 二次确认 → 站点确认
                         └─ 部分失败：展示失败阶段与建议处理
```

#### 5.6.3 音视频诊断流程

```text
进入模块 → 默认测点与最近15天自动查询
  → 选择音频/视频测点 → 自动适配并全选兼容指标
  → 修改时间或指标 → 点击“确定”
  → 查看同步趋势与数据列表
  → 选择样本
  ├─ 正常无附件：查看数值与上下文
  ├─ 有附件：默认展开图片/视频/音频证据
  └─ 报警：查看独立阈值依据与处置上下文
       → 标注/误信号/波形分析/导出
```

#### 5.6.4 通用异常恢复

- 读取失败：保留页面框架和已知上下文，局部显示失败原因与重试；不得用空数据伪装失败。
- 写入超时：先按 `operationId` 查询结果，再决定是否允许重试，避免重复操作。
- 对象离线：保留只读数据和最后更新时间，禁用依赖在线状态的操作。
- 无权限：隐藏不可发现的模块；对于可查看但不可操作的能力，保留按钮禁用态并说明权限要求。
- 数据版本冲突：禁止静默覆盖，展示最新修改人/时间（若有权限）以及重新加载入口。

#### 5.7.1 关键数据口径

| 口径 | 规则 | 边界情况 |
| --- | --- | --- |
| 今日新增 | `occurredAt` 位于当前站点时区自然日内的报警数 | 站点无时区时使用系统配置时区，不使用浏览器本地时区 |
| 今日处理 | 当日完成关闭的报警数 | 跨日关闭计入关闭发生日，不回写至报警发生日 |
| 今日转缺陷 | 当日成功创建缺陷编号的报警数 | 创建失败不计入；重复提交不得重复计数 |
| 待处理 | 当前状态为“待处理”的报警数 | 不受“今日”限制时，界面必须明确标注统计范围 |
| 完成率 | `（今日已关闭 + 今日已转缺陷）/ 今日新增 × 100%` | 今日新增为 0 时显示 100%，并在提示中说明口径 |
| 指标报警 | `样本值` 与该 `metricId` 当前生效阈值独立比较 | 其他指标报警不得污染当前样本；缺少阈值时显示“未配置”，不判红 |
| 时间范围 | 查询使用闭区间 `[startTime, endTime]`，统一传输 ISO 8601 时间 | UI 展示到毫秒；服务端按站点时区解释和聚合 |

### 5.8 后端接口边界

| 领域 | 读取能力 | 写入/任务能力 | 产品要求 |
| --- | --- | --- | --- |
| 设备域 | 设备树、状态统计、能力、用户选择偏好 | 保存偏好 | 树节点 ID 稳定；状态增量更新不改变层级与选择 |
| 视频域 | 播放地址、流状态、录像列表、回放地址 | 画质切换、云台、对讲、补光、雨刷、录像、重启 | 每路流独立失败；控制指令返回受理与最终结果 |
| 报警域 | 今日统计、分页列表、详情、附件、处置记录 | 关闭报警、转缺陷 | 状态变更返回最新报警和统计版本；转缺陷成功必须返回 `defectId` |
| 采集站域 | 列表、详情、属性、配置、自检记录、关联设备 | 配置保存、自检、重启、文件任务、设备关联 | 保存与下达分离；网络变更和重启明确中断影响 |
| 算法域 | 算法目录、数据 ID 候选、绑定、参数、区域 | 绑定保存、参数下发、区域坐标保存 | 支持已有绑定锁定、增量合并、部分失败明细 |
| 分析域 | 测点、指标、阈值、时序数据、附件 | 误信号、标注、导出任务 | 保留毫秒精度；指标报警独立；附件使用短期签名地址 |

读取接口必须区分成功空数据与请求失败。列表/树请求失败时不得返回空数组伪装成功；部分数据不可用时通过 `warnings` 或分项状态说明，不阻断其他可用数据。

#### 5.8.1 通用接口约定

| 项目 | 约定 |
| --- | --- |
| 读取接口 | 返回 `data`、`dataVersion`、`serverTime`；分页接口同时返回 `page`、`pageSize`、`total` |
| 写入接口 | 返回 `operationId`、`status`、`dataVersion`、`errorCode`、`message`；异步任务同时返回进度查询标识 |
| 幂等 | 高风险或可重复点击的写操作携带幂等键；相同键不得产生第二次业务结果 |
| 并发控制 | 保存时提交读取到的 `dataVersion`；版本冲突返回明确错误，不允许静默覆盖 |
| 错误处理 | 区分参数错误、无权限、对象离线、版本冲突、超时和系统错误；前端按错误类型提供定位或重试 |
| 时间 | 传输使用带时区的 ISO 8601；时序样本保留毫秒精度；响应包含服务端时间用于判断数据过期 |
| 安全 | 密码、Token、真实流地址不进入埋点和日志；下载/媒体使用短期签名地址 |

具体 URL、字段枚举、错误码和示例报文由研发文档定义，但不得改变上述产品语义。

## 六、性能预期

### 6.1 速度

- 企业内网桌面环境首屏可交互时间 ≤ 3 秒。
- 路由切换可见反馈 ≤ 200ms；普通前端状态操作反馈 ≤ 100ms。
- 普通列表查询接口 P95 ≤ 2 秒；写操作 P95 ≤ 3 秒；超时必须允许安全重试。
- 设备树达到 1000 节点、报警列表达到 500 条时使用虚拟滚动或分页。
- 大模块按路由拆包，单个首屏 JavaScript 包建议 ≤ 500kB gzip。

### 6.2 稳定性

- 前端页面可用性目标 ≥ 99.9%。
- 单路视频播放失败不得阻塞其他画面；单路重连互不影响。
- 实时数据断开后保留最后更新时间，并标识“数据已暂停更新”。
- 重复提交使用按钮锁定和幂等键，避免产生重复操作。
- 关闭页面、切换站点或刷新前，如存在未保存配置必须提示。

### 6.3 安全性

- 生产环境强制 HTTPS。
- 前端不得保存设备密码、Token 或真实流媒体密钥。
- 下载和媒体地址使用短期签名 URL。
- 用户输入统一校验和转义，写操作执行服务端权限校验。
- 高风险操作二次确认并保留审计日志。

## 七、兼容说明

### 7.1 浏览器与设备

- 桌面端支持当前及前一个主要版本的 Chrome、Edge。
- 重点适配 1440×900、1600×1000、1920×1080 和 2048×1098 工作站。
- 500px 以下提供基础浏览和菜单抽屉；复杂配置允许横向滚动，不强制卡片化。
- 任意受支持宽度下，关键按钮不得重叠，视频和图表不得被右栏遮挡。

### 7.2 系统与部署

- 平台：OS；SC、Taurus 的复用范围待产品与研发确认。
- 支持企业内网 HTTP 试点环境；正式环境使用 HTTPS。
- 静态部署采用 Hash 路由，确保业务页刷新、前进和后退正常。

### 7.3 存量数据

- 现有设备、采集站、测点和算法绑定 ID 必须保持稳定，不因前端升级重新生成。
- 已有算法绑定加载后保持选中和锁定，新增功能只做合并，不覆盖原有配置。
- 缺少新字段的历史数据按兼容默认值读取，并在首次保存时补齐数据版本。
- 旧版标注区域需要由后端提供坐标转换方案；无法转换的数据保留原记录并标记待处理。
- 配置保存采用版本号或更新时间校验，发现数据已被他人修改时禁止静默覆盖。

### 7.4 可访问性

- 设备树通过语义属性表达层级、展开和选择状态。
- 图标按钮可聚焦并提供可理解的辅助文本。
- 在线、报警和选中状态不能只依赖颜色。
- 弹窗支持 Escape 关闭、焦点约束和关闭后的焦点恢复。
- 自动轮播提供暂停能力，并在鼠标悬停或键盘聚焦时暂停。
